# Dataset EDA

This directory contains the exploratory data analysis outputs for the Chest X-Ray Pneumonia dataset.

The analysis was performed read-only on the original dataset. No images were modified, renamed, moved, or deleted.

Main outputs:
- `eda_report.md` – full EDA report and conclusions
- `image_inventory.csv` – metadata for every image
- `patient_summary.csv` – patient/group-level summary
- `anomalies.csv` – flagged unusual images
- `brightness.csv` – brightness statistics

The original image dataset is not stored in GitHub.
