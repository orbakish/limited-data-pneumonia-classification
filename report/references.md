## Dataset

The project uses the **Chest X-Ray Images (Pneumonia)** dataset available on Kaggle. The dataset contains pediatric chest X-ray images organized into Normal and Pneumonia classes and is based on the data described by Kermany et al. (2018).

Additional references related to data augmentation, transfer learning, and explanation stability will be added during the project.
